# 🚀 다국어 ATS 이력서 빌더

브라우저에서 전문적인 이력서를 작성하고, 디자인을 변경하고, 저장 및 내보낼 수 있는 웹 기반 이력서 제작 도구입니다.

> **🌐 [라이브 데모](https://thedevhublab.github.io/Resume/)**

## ✨ 주요 기능

- A4 캔버스 기반 실시간 이력서 미리보기
- 전문적인 이력서 템플릿 4종
- 한국어·영어 인터페이스 전환
- 프로필 이미지 등록 및 삭제
- 브라우저 LocalStorage 자동 저장
- JSON 파일 내보내기 및 가져오기를 통한 데이터 백업·복원
- PDF 다운로드 및 인쇄 최적화
- 다크 모드 및 라이트 모드
- 경력·학력·프로젝트 항목 추가 및 삭제

## 🛠 기술 스택

- HTML5, CSS3, Vanilla JavaScript
- CSS Grid 및 Flexbox
- LocalStorage API 및 JSON 데이터 관리
- html2pdf.js
- Google Fonts (Inter)

## 📋 사용 방법

1. [라이브 데모](https://thedevhublab.github.io/Resume/)에 접속합니다.
2. 개인정보, 경력, 학력, 프로젝트, 기술 등을 입력합니다.
3. 이력서 템플릿과 언어를 선택합니다.
4. 미리보기를 확인한 뒤 PDF로 저장하거나 인쇄합니다.
5. JSON 내보내기·가져오기 기능으로 데이터를 백업하거나 복원합니다.

## 🔒 개인정보 및 데이터

이력서 데이터는 브라우저의 LocalStorage에 저장됩니다. 브라우저 데이터를 지우거나 앱의 데이터 삭제 기능을 사용하면 저장된 정보가 삭제될 수 있으므로, 보관이 필요한 경우 JSON 백업을 권장합니다.

## 🎯 프로젝트 목표

복잡한 문서 편집 프로그램 없이 브라우저에서 이력서를 간편하게 작성하고 관리하며 전문적인 형식으로 내보낼 수 있도록 돕는 것이 목표입니다.
