# 🚀 Ultimate Multilingual ATS Resume Builder

[한국어 버전으로 보기](./README.KR.md)

A browser-based resume builder designed to help users create, customize, manage, and export professional resumes.

> **🌐 [Live Demo](https://thedevhublab.github.io/Resume/)**

## ✨ Key Features

- Real-time resume preview on an A4 canvas
- Four professionally designed resume templates
- English and Korean language support
- Profile image upload and removal
- Automatic saving with browser LocalStorage
- JSON export and import for data backup
- PDF download and print optimization
- Dark and light themes
- Dynamic management of work experience, education, and projects

## 🛠 Technologies

- HTML5
- CSS3 (Grid, Flexbox, Print CSS)
- Vanilla JavaScript
- LocalStorage API
- JSON data management
- html2pdf.js
- Google Fonts (Inter)

## 📋 How to Use

1. Open the [Live Demo](https://thedevhublab.github.io/Resume/).
2. Enter your personal details, experience, education, projects, and skills.
3. Choose a template and interface language.
4. Preview the resume and export it as a PDF or print it.
5. Use JSON export/import to back up or restore resume data.

## 🔒 Privacy

Resume data is stored locally in your browser using LocalStorage. Clearing browser data or using the app's clear-data function may remove saved information, so export a JSON backup if you want to keep a copy.

## 🎯 Project Goal

To provide a simple and accessible tool for creating, customizing, and exporting professional resumes directly in the browser without requiring complex document editing software.
